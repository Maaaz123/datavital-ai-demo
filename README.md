# DataVital AI Healthcare Intelligence Demo

Public demonstration of the DataVital AI healthcare intelligence screens.

This site uses **synthetic data only**. It is not a live hospital system, it does not connect to a hospital, and it must not be used for clinical decisions.

The interactive app is the existing healthcare intelligence interface (39 demo screens), built for GitHub Pages at `/datavital-ai-demo/`. Sign in with any username and password. The form is prefilled with `demo` / `demo`.

Source for the interface is in `frontend/`. The files at the repository root are the static site GitHub Pages serves from `main`.
