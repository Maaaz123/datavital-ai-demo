# DataVital AI Healthcare Intelligence Demo

Public conceptual showcase for hospital leaders and investors.

https://maaaz123.github.io/datavital-ai-demo/

This site uses **synthetic data and simulated AI only**. It is not a live hospital system, it does not connect to a hospital, and it must not be used for clinical decisions. Predictions are illustrations. They are not clinically validated.

Open `/showcase` with no account. The earlier operational screens remain behind `/login` (`demo` / `demo`).

Source for the interface is in `frontend/`. The files at the repository root are the static site GitHub Pages serves from `main`.
